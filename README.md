# Projeto Final: Laboratório de Banco de Dados (Etapas 1 e 2)

Repositório oficial da equipe para o desenvolvimento do projeto prático da disciplina **Laboratório de Banco de Dados** da Universidade Católica de Brasília (UCB), semestre 2/2026.

---

## 📌 Tema do Projeto
* **Domínio Escolhido:** Oficina Mecânica
* **Descrição do Escopo:** O projeto simula o dia a dia de uma oficina mecânica de porte médio, controlando clientes, veículos, estoque de peças, mecânicos (internos e terceirizados por empresa parceira) e o ciclo completo de Ordens de Serviço (OS) com histórico de status e controle de garantias.
